# Healthcare-data-analytics
## 📌 Project Overview
This project focuses on analyzing healthcare data to improve patient outcomes, operational efficiency, and cost management. The analysis helps hospitals and healthcare providers make data-driven decisions.

## 🛠 Tools Used
- Advanced Excel
- SQL
- Power BI
- Tableau

## 📊 Key Objectives
- Analyze patient admission and discharge trends
- Monitor hospital occupancy and length of stay
- Identify high-cost treatments and departments
- Track key healthcare KPIs

## 🔧 Tasks Performed
- Data cleaning and preprocessing
- Handling missing and inconsistent medical records
- KPI calculation (Average Length of Stay, Bed Occupancy Rate, Readmission Rate)
- SQL queries for patient and treatment analysis
- Interactive dashboards in Power BI and Tableau

## 📈 Dashboards & Insights
- Patient demographics analysis
- Department-wise cost analysis
- Monthly admission and discharge trends
- Treatment effectiveness insights

## 📊 Outcome
Delivered interactive dashboards that provide clear insights into hospital performance, helping stakeholders optimize resources and improve patient care.
